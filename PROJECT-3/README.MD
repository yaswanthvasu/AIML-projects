PROJECT 3:

WINE QUALITY EXPLORATORY DATA ANALYSIS

Objective

The objective of this project is to explore the Wine Quality dataset and identify the factors affecting wine quality using Exploratory Data Analysis (EDA).

Dataset

Dataset Name: Wine Quality Dataset

Source: Kaggle

link:https://www.kaggle.com/datasets/rajyellow46/wine-quality

Tools & Libraries

Python

Pandas

NumPy

Matplotlib

Tasks Performed

Loaded the dataset

Explored the dataset
Handled missing values

Removed duplicate records

Performed descriptive statistics

Calculated the correlation matrix
Identified highly correlated features

Detected and treated outliers
Performed filtering and sorting

Created bar chart, line chart, histogram, and scatter plot

Project Outcome

The dataset was cleaned and analyzed successfully. Correlation analysis helped identify the features that are most closely related to wine quality. Visualizations provided a better understanding of the data distribution and feature relationships.
