PROJECT 4:

DIAMOND PRICE ANALYSIS 

OBJECTIVE

The objective of this project is to analyze the Diamonds dataset using Exploratory Data Analysis (EDA) and understand how different features affect the price of diamonds.

DATASET

Dataset Name: Diamonds Dataset

Source: Kaggle

Tools & Libraries

Python

Pandas

NumPy

Matplotlib

TASKS PERFORMED

Loaded the dataset

Explored the dataset
Checked missing values
Checked duplicate records

Performed descriptive statistics

Calculated the correlation matrix
Identified highly correlated features
Detected and treated outliers

Performed filtering and sorting
Created data visualizations
Key Findings
Carat has the strongest positive correlation with price.
Diamond dimensions (x, y, z) are also highly correlated with price.
Depth has very little relationship with price
