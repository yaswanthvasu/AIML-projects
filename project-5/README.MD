PROJECT 5

RETAIL PRICE ANALYSIS

Objective

The objective of this project is to perform Exploratory Data Analysis (EDA) on the Retail Sales Dataset to understand customer purchasing behavior, sales patterns, and the factors affecting the total sales amount.

Dataset Information

Dataset Name: Retail Sales Dataset

Source: Kaggle

Dataset Link: https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

Libraries Used

Pandas

NumPy

Matplotlib

Tasks Performed

Imported and explored the dataset

Checked missing values

Checked duplicate records

Calculated descriptive statistics

Performed correlation analysis
Identified highly correlated features

Detected outliers using the IQR method

Performed filtering and sorting
Created visualizations using Matplotlib

Visualizations

Bar Chart

Line Chart

Histogram

Scatter Plot

Key Findings

Price per Unit has the strongest positive correlation with Total Amount.
Quantity has a moderate positive correlation with Total Amount.

No missing values or duplicate records were found.
No outliers were detected in the Total Amount column.
